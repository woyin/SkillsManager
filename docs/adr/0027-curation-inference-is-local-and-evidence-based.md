# Curation inference is local and evidence-based

Initial Curation Plan recommendations use only locally available, auditable metadata and Team Catalog-declared mappings: language and package manifests, framework configuration, directory markers, and existing SkillsManager configuration. Every recommendation exposes its supporting evidence; no source code is uploaded, no model is called by default, and complete source content is not treated as an inference input.

Opaque or remote analysis would make a tool intended for daily project maintenance hard to trust and difficult to audit. Deterministic metadata signals are enough to produce useful first suggestions while preserving privacy, predictable behavior, and an opt-in path for deeper analysis later.
