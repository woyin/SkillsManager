# Team Catalog supports adoption and forking

SkillsManager will support a versioned Team Catalog alongside each user's personal Registry. Members can adopt Catalog entries as centrally managed shared originals or fork selected entries into their own Registry for independent change; this preserves team-wide consistency where wanted without making personal experimentation or project-specific overrides impossible.

The alternatives were a shared-only Registry, which makes local exceptions unsafe or cumbersome, and personal copies only, which loses governed, reproducible team defaults. The dual model requires explicit provenance and update semantics, but keeps ownership and blast radius understandable.
